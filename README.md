# 아키텍트 — 마크 서버를 지배하는 AI 관리자

## 1. 서버 설정 (한 번)
마크 서버 폴더의 `server.properties` 열어서:
```
enable-rcon=true
rcon.port=25575
rcon.password=아무비번
```
저장 → 서버 재시작. (Cobbleverse 등 모드팩도 동일. 서버 폴더 = CurseForge 인스턴스 폴더)

## 2. 설치·실행 (서버가 돌아가는 그 컴퓨터에서)
```
pip install requests
python mc_admin.py          # 처음엔 config.json 만들고 종료됨
```
`config.json` 채우기:
- `rcon.password` : 위에서 정한 비번
- `log_path` : 서버의 `logs/latest.log` 전체 경로
- `groq.api_key` : Groq 키 (폰 공이랑 같은 거)
- `owner_names` : 네 마크 닉네임 (이 사람 말은 명령으로 처리)

다시 `python mc_admin.py` → 채팅에 "아키텍트 온라인" 뜨면 성공.

## 3. 게임 안에서
| 누가 | 어떻게 | 결과 |
|---|---|---|
| 아무나 | `아키텍트 안녕?` / `공 지금 몇 시야` | 대답 (설정 변경은 거절) |
| 주인 | `!밤으로 바꿔` `!철수한테 다이아 5개` `!밤 되면 좀비 두 배 나오게 해` | 명령 실행 / 트리거 생성 |
| 자동 | 접속 → 환영, 사망/도전과제 → 코멘트, 욕·광고·도배 → 경고 3회 킥 | |

콘솔 창에서도: 그냥 치면 아키텍트한테 말하기, `/명령` 치면 RCON 직접.

## 4. 트리거 (config.json → triggers)
`when` 값: `night` `day` `join` `leave` `death` `players>=5` `every:600`(초)
```json
{"name":"밤 좀비 두배","when":"night","enabled":true,
 "commands":["execute as @a at @s run summon minecraft:zombie ~3 ~ ~3"],
 "say":"밤이 왔다.","cooldown_sec":600}
```
`{player}` 쓰면 해당 플레이어 이름으로 치환. 게임 안에서 `!트리거 목록`, `!밤 좀비 두배 꺼` 로도 관리.

## 5. 디스코드 (선택)
config `discord.enabled=true`, 봇 토큰, 채널 ID → `pip install discord.py`
- 마크 채팅 ↔ 디스코드 채널 양방향
- 디스코드에서 `!명령` → 관리자 역할만 명령 가능

## 6. 폰 공에서 조종
mc_admin 이 포트 8791 로 HTTP 입구를 열어둠. VPS가 아니라 집 PC면 cloudflared로:
```
cloudflared tunnel --url http://localhost:8791
```
→ 폰 공 ⚙ → "마크 서버 URL"에 주소, 토큰은 config `http.token` (비워두면 토큰 없음)
그다음 폰에서: "아키텍트한테 밤으로 바꾸라고 해", "마크 서버 누구 있어"

## 7. 미니게임 32개 (`!게임 목록`)
| 채팅 게임 | 액션 게임 | 대결/파티 |
|---|---|---|
| 숫자 맞추기, 끝말잇기(AI 판정), 퀴즈, AI 퀴즈(주제 지정), 스피드 타이핑, 가위바위보, 투표, 왕 게임, 암살자 | 좀비 서바이벌, 몹 사냥, 광부 레이스, 낚시 대회, 마라톤, 점프 대결, 눈싸움, 보물찾기, 화염구 피하기, 번개 피하기, 크리퍼 런, 보스전(위더/가디언/좀비왕) | 결투 A B, 술래잡기, 숨바꼭질, 러시안 룰렛, 무중력 파티, 파쿠르 x y z, 건축 배틀, 폭탄 돌리기, 스플리프 x y z, 한 발 승부, 스모 A B x y z |

`!게임 좀비` 처럼 줄여도 됨. 우승자는 코인 보상 + 전적 기록. AI에게 "심심해" 하면 알아서 제안.

## 8. 서버 기능 (`!도움`)
- **경제**: 플레이 1분당 1코인, `!출석` 20코인, 게임 우승 보상 · `!돈` `!송금` `!상점`(10종) `!구매`
- **통계/랭킹**: `!통계` `!랭킹`(코인·플레이타임·킬·승리) `!데스`
- **편의**: `!집 저장`/`!집` `!좌표` `!시간` `!칭호 광부`(커스텀 100코인) `!룰`
- **참여**: `!날씨투표` `!시간투표` `!신고 이름 이유` `!건의 내용`
- **자동**: 첫 접속 선물+환영, 재접속 인사(플레이타임·메모), 데스 좌표 귓속말, AFK 10분 감지(알림/킥 선택), 캡스락 경고
- **운영 자동화**: 1시간마다 월드 백업(zip, 10개 보관), 15분마다 공지 로테이션, 40분마다 랜덤 이벤트(유성우·황금시간·상인·무중력·보너스·좀비습격·뇌우·하늘선물), 22시 AI 서버 일지(디스코드로도)
- **운영진 명령**: `!백업` `!공지` `!이벤트 [이름]` `!afk 킥/꺼` `!운영진 이름` `!리셋돈` `!일지` `!신고목록` `!건의목록`
- **AI 기억**: 플레이어가 "나 건축 좋아해" 하면 아키텍트가 기억 → 다음 접속 때 써먹음
- 주기/보상/백업 경로는 `config.json` → `features` 에서 조절. `world_dir` 비우면 자동 추정.

## 안전장치
- `stop` `op` `deop` `ban-ip` `whitelist off` 는 AI가 못 씀 (콘솔에서 직접)
- 일반 플레이어는 명령/경고/트리거 도구 못 씀 — 대화만
- `auto_moderation: false` 로 두면 경고만 알리고 자동 킥 안 함 (처음엔 이걸로 며칠 보는 거 추천)
- 경고 횟수는 `state.json` 에 저장, 재시작해도 유지
